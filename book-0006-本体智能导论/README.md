# 《本体智能导论》 · Introduction to Ontological Intelligence

一部系统论述「本体智能」的中文学术专著：面向概念与关系的形式化表示、知识组织与可判定推理的理论、方法与工程体系。全书以「从数据到知识、从知识到推理」为理论基础、以「本体论与知识表示」为核心、以「概念—知识—推理—应用」为脉络，把哲学、逻辑学、语义网、知识工程与神经—符号方法中彼此隔离的本体思想放进同一张地图。
