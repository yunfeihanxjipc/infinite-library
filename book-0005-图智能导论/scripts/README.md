# 《图智能导论》 · Introduction to Graph Intelligence

一部系统论述「图智能」的中文学术专著：面向关系化、网络化、非欧数据的表示、学习、推理与系统的理论、方法与工程体系。全书以「关系结构与消息传递作为归纳偏置」为理论基础、以「图神经网络」为核心、以「表示—学习—推理—系统」为脉络，把图论、谱理论、网络科学、表示学习与深度学习中彼此隔离的方法放进同一张地图。
