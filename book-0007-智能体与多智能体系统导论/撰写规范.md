# 《智能体与多智能体系统导论》书籍级撰写规范

> 本文件是全书内容与质量的**统一标尺**。配套：`前置说明.md`（书的前置说明）、`chapters/`（正文唯一真源）、`插图规划.md`（配图占位说明）。沿用《时序智能导论》的《撰写规范》作为统一标尺。

---

## 1. 篇幅配额（硬指标）

以**正文有效中文字符**计（LaTeX 行内/独立公式按其所表达的内容折算，不按字符数灌水）。用户指定的本章文件篇幅为每章 130–180 行。

| 层级 | 配额 | 说明 |
|------|------|------|
| 章导读 | 400–600 字 | 交代本章问题、为何重要、在全书中的位置、阅读路径，2–3 个自然段 |
| 每一节 | 1200–2000 字 | 核心理论/推导节 2000–3000 字；不得少于 4 个成段自然段 |
| 每章正文合计 | 一般章 6000–9000 字；核心章 9000–12000 字 | 见逐章规划 |
| 本章小结 | 400–600 字 | 一段综述 + 分点梳理，须回扣本章主线 |
| 每章全文件 | 130–180 行 | 含公式、图表说明、参考文献 |

> 判据：任意抽取一节，若可压缩成不到 4 句话的要点，即为不合格。

## 2. 每一节的「七要素」结构（成书笔法）

每节须依次、连贯地展开以下七层，**融入行文而非贴标签**：

1. **引入与动机**：为什么需要这个概念/方法？它要解决哪个具体困难？从上一节自然引出。
2. **直觉解释**：先不写公式，用一到两段把思想讲清楚（物理直觉、几何图像、统计含义）。
3. **严格定义与推导**：给出编号定义/定理/公式，并**给出推导过程或关键中间步骤**——不能只摆结论。核心公式须说明每个符号、成立条件。
4. **算例（例 X.Y）**：至少配一个带具体数字或具体对象的工作例，展示「代入公式会怎样」。
5. **技术谱系与变体**：该方法有哪些变体、各自针对什么局限、如何选型；用表格对照更佳。
6. **边界与讨论**：适用前提、假设违背时如何失效、常见误用、与其他方法的比较。
7. **承上启下**：点明与本章下一节及全书其他章的联系（显式交叉引用）。

> 禁止用「是什么 / 怎么用 / 技术有哪些 / 技术细节」作小标题；成书须用连贯学术散文承载同样的信息。

## 3. 每章必备清单（逐章验收）

- [ ] **章导读**：2–3 段，含问题意识与全书定位。
- [ ] **定义/定理**：≥ 2 个，`**定义 X.Y（名称）**` / `**定理 X.Y**`，措辞严格。
- [ ] **编号公式**：行内 `$...$`、独立 `$$...\tag{X-N}$$`；核心公式有推导。
- [ ] **例**：≥ 2 个，`**例 X.Y**`，含具体数值或具体对象。
- [ ] **图**：≥ 1 张，正文有引用句 + 引用块占位 `> 【图 X-Y　标题】（原图见 figures/图X-Y.png）：绘制说明` 与 `![图 X-Y　标题](figures/图X-Y.png)`。
- [ ] **表**：≥ 1 张，`**表 X-Y　标题**`，用于分类/对照/复杂度比较。
- [ ] **文内引用标号**：正文论断处标注 `[n]`，与章末参考文献一一对应。
- [ ] **参考文献**：8 条（用户硬性要求），须含奠基文献、经典教材、近三年前沿、综述各若干。
- [ ] **本章小结**：一段综述 + 分点，非三句 bullet。
- [ ] **进一步阅读** 小节。
- [ ] **交叉引用**：显式指向相关章节（含章号）。
- [ ] **环路四问**：每章必答——处于环路哪一环、隐含什么假设、突破前法什么限制、无法突破什么理论边界。
- [ ] **体例**：中文全角标点，节号后全角空格 `　`，术语首现给英文，无「习题」小节。

## 4. 体例与编号（全书一致）

| 对象 | 格式 | 例 |
|------|------|----|
| 章 | `# 第 N 章　标题` | `# 第 3 章　规划与搜索` |

> 公式用 Python raw 字符串 `r'''...'''` 写入脚本执行，确保反斜杠正确。配图以占位说明形式给出，正文的图引用句与占位块须齐全。

## 5. 反模式清单（禁止）

1. 整节只有 bullet 列表、无成段论述。
2. 公式只给结论、无推导或符号说明。
3. 无算例、无具体数字。
4. 罗列模型名而不解释设计动机。
5. 文内无引用标号、文献与正文脱节。
6. 「本章介绍了……」之类空泛过渡句堆字数。
7. 使用标签式小标题组织内容。
8. 为凑篇幅重复同一论断。

## 8. 理论主线与去重原则

### 8.1 每章必答「环路四问」

每介绍一个方法须回答：① 处于环路哪一环（感知/推理/行动/记忆）；② 隐含什么假设；③ 突破前一方法的什么限制；④ 无法突破什么理论边界。

### 8.2 基础理论只讲一次

- 决策论、Bellman 方程 → 只在第 2 章完整推导；第 28 章强化学习交叉引用。
- 经典规划、STRIPS → 只在第 3 章；第 11、12 章引用。
- ReAct 循环 → 只在第 7 章完整展开；第 15—19 章调用。
- 世界模型七要素 → 《世界模型导论》；本书第 13 章只作交叉引用。
- 注意力、预训练 → 《自然语言智能导论》；本书第 6、10 章按需引用。
- 推理形式化、安全对齐 → 《推理与对齐导论》；本书第 14、35 章只作交叉引用。

### 8.3 统一案例：自动化软件开发智能体

全书以一名「自动化软件开发智能体」为贯穿案例（第 1.6 节）。同一任务在不同章复用：搭架构（5）、走循环（7）、分解任务（11）、工具与代码执行（15—16）、建记忆（20—23）、多智能体团队（25）、辩论评审（27）、完整评估（34）；辅以研究助手、浏览器智能体与客服智能体的专题案例。
