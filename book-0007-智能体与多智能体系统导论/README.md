# 《智能体与多智能体系统导论》 · Introduction to Agents and Multi-Agent Systems

一部系统论述「智能体与多智能体系统」的中文学术专著：从对话到自主行动、从单体到协同，覆盖智能体感知环境、规划行动、使用工具并相互协作的理论、方法与工程体系。全书以「自主规划与协作」为理论基础、以「推理—行动环路」为核心、以「感知—推理—行动—记忆」为脉络，把决策论、规划、博弈论、大语言模型与分布式系统中彼此隔离的智能体思想放进同一张地图。
