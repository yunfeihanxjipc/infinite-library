# 《科学智能导论》书籍级撰写规范

> 本文件是全书内容与质量的**统一标尺**。配套：`前置说明.md`（书的前置说明）、`chapters/`（正文唯一真源）、`插图规划.md`（配图占位说明）、`附录.md`。

---

## 1. 篇幅配额（硬指标）

以**正文有效中文字符**计（LaTeX 行内/独立公式按其所表达的内容折算，不按字符数灌水）。

| 层级 | 配额 | 说明 |
|------|------|------|
| 章导读 | 400–600 字 | 交代本章问题、为何重要、在全书中的位置、阅读路径，2–3 个自然段 |
| 每一节 | 1200–2000 字 | 核心理论/推导节 2000–3000 字；不得少于 4 个成段自然段 |
| 每章正文合计 | 一般章 6000–9000 字；核心章 9000–12000 字 | 见逐章规划 |
| 本章小结 | 400–600 字 | 一段综述 + 分点梳理，须回扣本章主线 |

> 当前批次（第 1—21 章）以**每章 130–180 行**为交付粒度，行内含完整七要素、公式、图表与文献。

## 2. 每一节的「七要素」结构（成书笔法）

每节须依次、连贯地展开以下七层，**融入行文而非贴标签**：

1. **引入与动机**：为什么需要这个概念/方法？它要解决哪个具体困难？从上一节自然引出。
2. **直觉解释**：先不写公式，用一到两段把思想讲清楚（物理直觉、几何图像、统计含义）。
3. **严格定义与推导**：给出编号定义/定理/公式，并**给出推导过程或关键中间步骤**——不能只摆结论。核心公式须说明每个符号、成立条件。
4. **算例（例 X.Y）**：至少配一个带具体数字或具体对象的工作例，展示「代入公式会怎样」。
5. **技术谱系与变体**：该方法有哪些变体、各自针对什么局限、如何选型；用表格对照更佳。
6. **边界与讨论**：适用前提、假设违背时如何失效、常见误用、与其他方法的比较。
7. **承上启下**：点明与本章下一节及全书其他章的联系（显式交叉引用）。

> 禁止用「是什么 / 怎么用 / 技术有哪些 / 技术细节」作小标题；成书须用连贯学术散文承载同样的信息。

## 3. 每章必备清单（逐章验收）

- [ ] **章导读**：2–3 段，含问题意识与全书定位。
- [ ] **定义/定理**：≥ 2 个，`**定义 X.Y（名称）**` / `**定理 X.Y**`，措辞严格。
- [ ] **编号公式**：行内 `$...$`、独立 `$$...\tag{X-N}$$`；核心公式有推导。
- [ ] **例**：≥ 2 个，`**例 X.Y**`，含具体数值或具体对象。
- [ ] **图**：≥ 1 张，正文有引用句 + 占位块 `> 【图 X-Y　标题】（原图见 figures/图X-Y.png）：绘制说明` + `![图 X-Y　标题](figures/图X-Y.png)`。
- [ ] **表**：≥ 1 张，`**表 X-Y　标题**`。
- [ ] **文内引用标号**：正文论断处标注 `[n]`，与章末参考文献一一对应。
- [ ] **参考文献**：8 条真实文献（含奠基文献、经典教材、近三年前沿、综述）。
- [ ] **本章小结**：一段综述 + 分点，回扣本章主线。
- [ ] **进一步阅读**：列明建议延伸的文献编号。
- [ ] **交叉引用**：显式指向相关章节（含章号）。
- [ ] **体例**：中文全角标点，节号后全角空格「　」，术语首现给英文，无「习题」小节。

## 4. 体例与编号（全书一致）

| 对象 | 格式 | 例 |
|------|------|----|
| 章 | `# 第 N 章　标题` | `# 第 3 章　微分方程与数值方法` |
| 节 | `## N.M　标题` | `## 3.2　数值方法：有限差分、有限元、谱方法` |
| 定义/定理/例 | `**定义 X.Y（名称）**` / `**例 X.Y**` | `**定义 5.1（物理信息神经网络）**` |
| 独立公式 | `$$...\tag{X-N}$$` | `$$\mathcal{L}=\mathcal{L}_{\mathrm{data}}+\lambda\mathcal{L}_{\mathrm{phy}}\tag{5-3}$$` |
| 图 | `图 X-Y` + 占位块 + 图片引用 | 见第 3 节 |
| 表 | `表 X-Y` | `**表 1-1　科学智能的四层能力**` |
| 文内引用 | `[n]` | `……由 Raissi 等提出[1]` |
| 参考文献 | `[n] 作者. 标题. 出处, 年份(卷期):页码.` | 见任意章末 |

> 公式须用 Python raw 字符串（r'''...'''）写入脚本执行，确保反斜杠（如 `\mathcal`、`\partial`、`\nabla`）正确落盘，不被转义。

## 5. 反模式清单（禁止）

1. 整节只有 bullet 列表、无成段论述。
2. 公式只给结论、无推导或符号说明。
3. 无算例、无具体数字。
4. 罗列模型名而不解释设计动机。
5. 文内无引用标号、文献与正文脱节。
6. 「本章介绍了……」之类空泛过渡句堆字数。
7. 使用标签式小标题组织内容。
8. 为凑篇幅重复同一论断。
9. 退化为大纲或要点摘录，而非真正的学术专著正文。

## 7. 推进顺序与验收

1. **顺序**：按篇推进；基础章（1—4）先行，后续章交叉引用其内容。
2. **每章完成后**：对照第 3 节清单打勾；行数 130–180；随机抽一节确认含七要素；确认文内 `[n]` 与文献一一对应。
3. **公式**：用 raw 字符串脚本写入，写后抽查反斜杠与 `\tag{X-N}` 编号正确。
4. **配图**：占位块 + 图片引用齐全，新增图同步补进 `插图规划.md`，保持图号一致。
5. **清理**：交付前删除 `scripts/` 下临时脚本。

> 质量优先于数量：真正的学术专著正文，而非大纲。

## 8. 统一案例与去重原则

### 8.1 统一案例

以**一个贯穿全书的流体动力学问题（Navier–Stokes 方程与湍流）与分子性质预测**为统一案例：第 3 章数值求解，第 5 章 PINN，第 6 章神经算子，第 16、18 章基础模型，第 20 章符号回归发现方程，第 25—26 章实验设计，第 28—30 章 AI Scientist 流程。辅以气候、材料、蛋白质与药物发现专题。基础理论只讲一次，后续以交叉引用展开。

### 8.2 与系列其他书的去重

- **与《世界模型导论》**：第 5、6 章 PINN 与神经算子只讲「科学建模侧」，不展开动作条件化与规划；科学世界模型与潜在动力学归世界模型书。
- **与《时序智能导论》**：第 18 章气候与流体预测的时序方法作交叉引用；时序预测完整体系归时序书。
- **与《图智能导论》**：第 10、16 章分子图与 GNN 作交叉引用；GNN 完整体系归图智能书。
- **与《因果智能导论》**：第 21 章物理定律发现与因果发现的联系点到为止；完整体系归因果书。
- **与《本体智能导论》**：第 23 章科学假设与知识表示点到为止；本体与知识表示归本体书。

### 8.3 每章必答「循环四问」

① 处于「数据—建模—发现—实验」循环的哪一环；② 隐含什么假设；③ 突破了前一方法的什么限制；④ 无法突破什么理论边界。
