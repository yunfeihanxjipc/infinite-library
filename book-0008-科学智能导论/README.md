# 《科学智能导论》 · Introduction to AI for Science

一部系统论述「科学智能」（AI for Science）的中文学术专著：以「物理约束下的可泛化建模」为理论基础、以「科学基础模型」为核心、以「数据—建模—发现—实验」为脉络，把数值计算、物理建模、机器学习与科学发现自动化彼此隔离的方法放进同一张地图。全书追问一个根本问题：**人工智能能否不仅拟合科学数据，更能发现科学规律、加速科学发现？**

## 自建理论框架

**科学智能的四层能力**：科学数据（Level 1）→ 科学建模（Level 2）→ 科学发现（Level 3）→ 科学实验（Level 4），四层构成「观察 → 假设 → 建模 → 验证 → 新观察」的科学发现循环。

**统一案例**：贯穿全书的 Navier–Stokes 方程与湍流（数值求解 → PINN → 神经算子 → 基础模型 → 符号回归 → 自主发现），辅以分子性质预测、气候、材料、蛋白质与药物发现专题。
