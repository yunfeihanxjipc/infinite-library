# 《世界模型导论》书籍级撰写规范

> 本文件是全书内容与质量的**统一标尺**。配套：`前置说明.md`（书的前置说明）、`chapters/`（正文唯一真源）、`插图规划.md`（配图占位说明）。

---

## 1. 篇幅配额（硬指标）

以**正文有效中文字符**计（LaTeX 行内/独立公式按其所表达的内容折算，不按字符数灌水）。

| 层级 | 配额 | 说明 |
|------|------|------|
| 章导读 | 400–600 字 | 交代本章问题、为何重要、在全书中的位置、阅读路径，2–3 个自然段 |
| 每一节 | 1200–2000 字 | 核心理论/推导节 2000–3000 字；不得少于 4 个成段自然段 |
| 每章正文合计 | 一般章 6000–9000 字；核心章 9000–12000 字 | 见逐章规划 |
| 本章小结 | 400–600 字 | 一段综述 + 分点梳理，须回扣本章主线 |
| 每章全文件字符 | ≥ 8000（一般）/ ≥ 12000（核心） | 含公式、图表说明、参考文献 |

> 判据：任意抽取一节，若可压缩成不到 4 句话的要点，即为不合格。

## 2. 每一节的「七要素」结构（成书笔法）

每节须依次、连贯地展开以下七层，**融入行文而非贴标签**：

1. **引入与动机**：为什么需要这个概念/方法？它要解决哪个具体困难？从上一节自然引出。
2. **直觉解释**：先不写公式，用一到两段把思想讲清楚（物理直觉、几何图像、统计含义）。
3. **严格定义与推导**：给出编号定义/定理/公式，并**给出推导过程或关键中间步骤**——不能只摆结论。核心公式须说明每个符号、成立条件。
4. **算例（例 X.Y）**：至少配一个带具体数字或具体对象的工作例，展示"代入公式会怎样"。
5. **技术谱系与变体**：该方法有哪些变体、各自针对什么局限、如何选型；用表格对照更佳。
6. **边界与讨论**：适用前提、假设违背时如何失效、常见误用、与其他方法的比较。
7. **承上启下**：点明与本章下一节及全书其他章的联系（显式交叉引用）。

> 禁止用"是什么 / 怎么用 / 技术有哪些 / 技术细节"作小标题；成书须用连贯学术散文承载同样的信息。

## 3. 每章必备清单（逐章验收）

- [ ] **章导读**：2–3 段，含问题意识与全书定位。
- [ ] **定义/定理**：≥ 2 个，`**定义 X.Y（名称）**` / `**定理 X.Y**`，措辞严格。
- [ ] **编号公式**：行内 `$...$`、独立 `$$...\tag{X-N}$$`；核心公式有推导。
- [ ] **例**：≥ 2 个，`**例 X.Y**`，含具体数值或具体对象。
- [ ] **图**：≥ 1 张，正文有引用句（"图 X-Y 展示了……"）+ 引用块占位 `> 【图 X-Y　标题】（待绘制）：绘制说明`。
- [ ] **表**：≥ 1 张，`**表 X-Y　标题**`，用于分类/对照/复杂度比较。
- [ ] **文内引用标号**：正文论断处标注 `[n]`，与章末参考文献一一对应。
- [ ] **参考文献**：核心章 12–16 篇、一般章 8–12 篇；须含奠基文献、经典教材、近三年前沿、综述各若干。
- [ ] **本章小结**：一段综述 + 分点，非三句 bullet。
- [ ] **交叉引用**：显式指向相关章节（含章号）。
- [ ] **体例**：中文全角标点，节号后全角空格 `　`，无"习题"小节。

## 4. 体例与编号（全书一致）

| 对象 | 格式 | 例 |
|------|------|----|
| 章 | `# 第 N 章　标题` | `# 第 3 章　语言的概率与信息论基础` |
| 节 | `## N.M　标题` | `## 3.2　熵、交叉熵与困惑度` |
| 定义/定理/例 | `**定义 X.Y（名称）**` / `**例 X.Y**` | `**定义 3.2（交叉熵）**` |
| 独立公式 | `$$...\tag{X-N}$$` | `$$H(p,q)=-\sum_x p(x)\log q(x)\tag{3-6}$$` |
| 图 | `图 X-Y` + 引用块占位 + 图片引用 | `图 3-1 展示了……` |
| 表 | `表 X-Y` | `**表 3-1　……**` |
| 文内引用 | `[n]` | `……由 Shannon 系统化[1]` |
| 参考文献 | `[n] 作者. 标题. 出处, 年份(卷期):页码.` | 见任意章末 |

> 当前阶段配图以占位说明形式给出（图片引用行可保留但图片待绘制），正文的图引用句与占位块须齐全。

## 5. 反模式清单（禁止）

1. 整节只有 bullet 列表、无成段论述。
2. 公式只给结论、无推导或符号说明。
3. 无算例、无具体数字。
4. 罗列模型名而不解释设计动机。
5. 文内无引用标号、文献与正文脱节。
6. "本章介绍了……" 之类空泛过渡句堆字数。
7. 使用标签式小标题组织内容。
8. 为凑篇幅重复同一论断。

## 7. 推进顺序与验收

1. **顺序**：按篇推进；基础章（1–4）先行，后续章交叉引用其内容。
2. **每章完成后**：按拼接命令重建 `世界模型导论-全稿.md`。
3. **验收**：逐条对照第 3 节清单打勾；字数达标；随机抽一节确认含"七要素"；确认文内 `[n]` 与文献一一对应。
4. **配图**：当前以占位说明给出，新增/改动的图同步补进 `插图规划.md`，保持图号一致。

> 质量优先于数量：宁可一章写足 12000 字，不可十章各写 1500 字。

## 8. 深度分级与统一章节结构

### 8.1 A/B/C 三级写作深度

| 等级 | 写作要求 | 示例 |
|------|----------|------|
| **A 核心理论** | 数学推导、定理、证明、算法、算例，篇幅最足 | 形式语言、信息论、word2vec、句法分析、组合语义、注意力、预训练、RLHF |
| **B 重要方法** | 原理、关键公式、算法、实验比较 | CRF、ELMo、NMT、LoRA、RAG、多模态 |
| **C 扩展方法** | 核心思想、适用场景、优缺点、文献 | 各类变体与专门应用 |

C 类内容允许精简，但**不得退化为「整节只有 3–5 个 bullet」**。

### 8.2 每章统一 9 段结构

融入连贯学术行文，不贴标签：① 本章导读与核心问题；② 历史背景与方法起源；③ 数学定义与理论基础；④ 模型推导与算法原理；⑤ 关键技术变体；⑥ 算例与实验（含统一案例）；⑦ 方法比较与适用边界；⑧ 本章小结；⑨ 进一步阅读与参考文献。

### 8.3 统一案例：倒立摆与推箱子机器人

以贯穿全书的物理交互任务（倒立摆控制 + 推箱子机器人）为主案例（第 1.8 节），相关章在「算例与实验」段复用同一环境，展示从状态估计、经典控制、潜在动力学、视频世界模型到规划的完整链条；辅以自动驾驶、天气、游戏与机器人操作专题案例（第 31 章）。

## 9. 理论主线与去重原则

### 9.1 每章必答「七要素四问」

每介绍一个模型须回答：① 具备哪几个要素（E1 状态表示 / E2 状态转移 / E3 观测生成 / E4 不确定性 / E5 动作条件化 / E6 奖励目标 / E7 规划）；② 隐含什么假设；③ 突破前一模型的什么限制；④ 无法突破什么理论边界。

### 9.2 基础理论只讲一次

- 状态空间与卡尔曼滤波 → 只在第 2、5 章完整推导；第 13、28、31 章交叉引用。
- VAE 与 ELBO → 只在第 9 章；第 10、14 章引用。
- 扩散模型 → 只在第 14 章完整推导；第 15、16、18 章引用。
- 注意力机制 → 只在《自然语言智能导论》第 20 章；本书第 16、27 章按需引用。
- MBRL 与规划 → 只在第 24、25 章完整展开；第 27、32 章调用。
