# 《因果智能导论》 · Introduction to Causal Intelligence

一部系统论述「因果智能」的中文学术专著：面向从数据中学习因果结构、估计因果效应并支撑干预与反事实推理的理论、方法与工程体系。全书以**因果之梯（关联—干预—反事实）**为理论基础、以**结构因果模型**为核心、以「表示—发现—效应—决策」为脉络，把统计学、计量经济学、机器学习与哲学中彼此隔离的因果思想放进同一张地图。

## 理论主线

因果智能包含三层递进的能力——**关联、干预、反事实**（因果之梯），并进一步分为四层递进的能力——**因果表示、因果发现、因果效应、因果决策**。全书对每一个方法追问四件事：它站在因果之梯的哪一级、隐含了什么假设、突破了前一方法的什么限制、无法突破什么理论边界。第 1 章立框架，第 2—4 章建立理论基础，第 32 章据此评估大模型的因果推理能力，第 41 章回扣框架讨论因果智能能否通向通用智能，形成首尾闭环。
